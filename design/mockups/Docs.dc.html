Connect Cloudflare R2

R2 has no egress fees, which makes it a good default for image-heavy sites. You need a bucket and an R2 API token with read and write access.

1. Create an API token

In the Cloudflare dashboard open R2 → Manage API tokens and create a token with Object Read & Write on your bucket. Copy the Access Key ID and Secret Access Key. The secret is shown once.

2. Fill in the setup wizard

Fields for Cloudflare R2
FieldWhere to find it
BucketYour R2 bucket name, for example nimbus-media
R2 Account IDDashboard → Overview. Plume builds the endpoint from it.
Access KeyAccess Key ID from the token
Secret KeySecret Access Key from the token
Endpoint (optional)Leave empty unless you use a custom R2 endpoint

Tip: connect a custom domain to the bucket in Cloudflare, then set it as the delivery domain in Plume so files are cached at the edge.

3. Test and offload

Select Test connection. When it passes, new uploads go to R2. To move existing files, start a bulk job from Tools or run:

$ wp nimbus sync --limit=500
