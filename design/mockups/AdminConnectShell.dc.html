Where should your media live?

Connect Amazon S3

Run one command in your AWS account. Nothing leaves AWS except the line you paste back.

  2. Open AWS CloudShellSign in to the AWS account that should hold your media.
    Open CloudShell
  3. Paste this command into CloudShell
    B=example-site-media R=eu-west-2 U=nimbus-example-site-media
aws s3api create-bucket --bucket $B --region $R \
  --create-bucket-configuration LocationConstraint=$R
aws s3api put-public-access-block --bucket $B --public-access-block-configuration \
  BlockPublicPolicy=false,RestrictPublicBuckets=false,BlockPublicAcls=true,IgnorePublicAcls=true
aws iam create-user --user-name $U >/dev/null
