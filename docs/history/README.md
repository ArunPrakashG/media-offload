# docs/history/

Archived planning and marketing-positioning docs from when Plume was a
paid, commercially-licensed plugin. Kept for historical context only —
none of it reflects the current product, which is fully free and open
source with no license tiers.

- `refactor-roadmap.md` — the original architecture plan written when
  converting an older plugin into the commercial "Plume" product.
- `features.md` — an internal free/personal/pro/agency feature matrix and
  marketing notes from the paid era.
- `competitor-analysis.md` — a competitive analysis against WP Offload
  Media, framed around paid-tier positioning.

For current features, see [`apps/plugin/nimbus/README.md`](../../apps/plugin/nimbus/README.md)
and the live docs at the project website.
